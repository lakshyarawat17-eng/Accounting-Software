Email Settings (Brevo)
Used to send invoices to clients by email. Railway blocks outbound SMTP, so this app sends mail through Brevo's HTTPS API instead. Free account, no domain needed — just: 1) sign up at brevo.com, 2) verify a "from" sender email (Senders, Domains & Dedicated IPs → Senders), 3) create an API key (Settings → SMTP & API → API Keys), 4) paste it below.
