Company / GST Profile
Your own business details. The GSTIN here is what gets printed as the seller on every Sales Invoice PDF, and is compared against each client's GSTIN to automatically work out CGST+SGST vs IGST — so keep it up to date.
Drives the mandatory HSN digit length on Item Master (CBIC Notification 78/2020, as applied under GSTN's May-2025 GSTR-1 Table 12 rules): > ₹5 crore → 6-digit HSN required on every item · ₹5 crore or below → 4-digit required. HSN is mandatory on every item regardless of turnover — there is no longer an "optional" slab, since HSN reporting has no turnover exemption for B2B supplies.

Email Settings
Used to send invoices to clients by email. Railway blocks outbound SMTP, so this app sends mail through an HTTPS API instead. You only need ONE of the keys below — if more than one is filled in, priority is Resend, then Brevo, then SendGrid. Leave your "from" fields blank while testing with Resend on its shared sandbox address.
WhatsApp Settings
Used to send invoices to clients over WhatsApp. Two providers are wired up — Twilio and Meta's WhatsApp Cloud API (direct, no middleman). Both stay fully configured; the "Active Provider" dropdown just decides which one actually sends when you hit "Send via WhatsApp" or the test button below.
Option A — Twilio
Sign up at console.twilio.com to get an Account SID and Auth Token, then enable WhatsApp (the free Sandbox works for testing; a Twilio-approved Sender is needed for production). The "From" number must include the whatsapp: prefix, e.g. whatsapp:+14155238886.
Option B — Meta (WhatsApp Cloud API)
Sign up at developers.facebook.com, create an App, add the WhatsApp product. API Setup gives you a Phone Number ID and a token (use a permanent System User token for production, not the 24h temporary one). Business-initiated messages (every invoice notification) need an approved Message Template — create one under WhatsApp → Message Templates with 4 body variables to match Twilio's layout, or leave blank to use Meta's built-in hello_world template for the test button only.
